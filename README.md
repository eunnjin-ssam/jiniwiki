# 지니위키

초등교사 업무 수첩. 담임·부서·행정 업무를 **분류 · 시기(월) · 태그**로 정리해 검색하고, 직접 만든 웹도구를 한곳에 모아 둔다.

- 페이지: `jiniwiki.html` (claude.ai 아티팩트로 배포, 비공개)
- 데이터: 카드(`cards`)와 웹도구(`tools`)는 아티팩트 데이터 저장소에 있고, 이 저장소에는 들어 있지 않다. 백업은 페이지의 '전체 백업 받기'로 받는다.

## 구성
- 홈: 이번 달 할 일, 다음 달 미리 보기, 즐겨찾기, 웹도구, 최근 카드
- 검색: 낱말, 초성, `#태그`
- 월별 할 일: 3월부터 2월까지 학년도 순서
- 업무 분류: 담임업무 / 부서업무 / 행정·복무 / 수업·자료 / 헷갈리는 것
- 카드: 한 줄 요약, 체크리스트(학년도별), 절차, 주의할 점, 링크, 마지막 확인일
